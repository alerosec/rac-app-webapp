# AleroSec RAC

A Cloudflare-ready static prototype for evidence-backed risk and compliance workflows.

## What is included
- Static dashboard, risk, and compliance pages
- Local-first storage with auth demo flow
- Updated branding for AleroSec and the rac.alerosec.com target
- Deployment hints for Cloudflare Pages and security headers

## Suggested deployment steps
1. Connect the repository to Cloudflare Pages.
2. Set the build output directory to the project root.
3. Upload or publish the files directly as a static site.
4. Configure the custom domain rac.alerosec.com.
5. Add the provided _headers file for security response headers.
